Installation : télécharge RemontadaPlanner.zip, dézippe, double-clique sur RemontadaPlanner.exe. Aucune installation nécessaire.

Mise à jour depuis une version précédente : remplace simplement l'ancien RemontadaPlanner.exe par le nouveau. Tes données (%APPDATA%\DailyPlanner\plans.json) sont conservées.

Windows peut afficher un avertissement SmartScreen au premier lancement (exe non signé) : clique sur "Informations complémentaires", puis "Exécuter quand même".
